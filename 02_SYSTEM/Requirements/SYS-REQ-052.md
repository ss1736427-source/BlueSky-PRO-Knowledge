# SYS-REQ-052 — нтеграция со страховыми провайдерами

## Requirement

Система должна поддерживать интеграцию со страховыми организациями через стандартизированный интерфейс.

нтеграция должна обеспечивать возможность:

- передачи данных С;
- передачи данных эксплуатанта;
- передачи параметров операции;
- запроса страхового предложения;
- получения вариантов покрытия;
- получения статуса оформления;
- получения электронных данных полиса;
- проверки действительности полиса.

онкретный страховой провайдер не должен являться зависимостью ядра BlueSky.

спользуется архитектура:

BlueSky → Insurance Service → Provider Adapter → Insurance Provider.
