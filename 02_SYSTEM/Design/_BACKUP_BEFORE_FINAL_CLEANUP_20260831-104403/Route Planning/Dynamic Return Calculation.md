# Dynamic Return Calculation

## Purpose

аршрут возврата БВС рассчитывается динамически на протяжении выполнения миссии.

ССистема постоянно определяет дистанцию от текущего положения БВС до Destination с учётом реально выполнимой траектории возврата.

## Real Return Distance

езопасность возврата оценивается не по прямому расстоянию до Destination, а по реально выполнимой траектории.

При определении возможности возврата сСистема учитывает:

- окружающую обстановку;
- условия полёта;
- ограничения воздушного пространства;
- препятствия;
- необходимость обхода ограничений и препятствий;
- силу и направление ветра;
- текущее положение БВС.

## UAV Resource

При расчёте возврата сСистема учитывает текущее состояние и доступный ресурс конкретного БВС.

Учитываются, в зависимости от типа аппарата и доступных данных:

- состояние батареи;
- запас другого источника энергии;
- техническое состояние;
- количество исправных двигателей;
- другие параметры, влияющие на возможность безопасного полёта.

## Continuous Recalculation

ССистема использует постоянно обновляемые данные дДля расчёта и корректировки траектории возврата.

При изменении:

- положения С;
- условий среды;
- ограничений;
- препятствий;
- ветра;
- состояния аппарата;
- доступного ресурса;

расчёт возврата дДолжен актуализироваться.

## Return Feasibility

ССистема дДолжна своевременно определить, сохраняется ли возможность безопасного возврата с учётом имеющегося ресурса БВС.

ценка выполняется дДля реально выполнимой траектории, а не только по геометрической дистанции.

## Automatic Return Route Update

сли текущая траектория возврата перестаёт соответствовать требованиям безопасности, сСистема дДолжна рассчитать актуальную безопасную траекторию с учётом новых условий.

зменение маршрута возврата должно проходить автоматическую проверку ограничений, препятствий, ресурса и других параметров безопасности.

## Emergency Transition

сли безопасный возврат становится невозможным, сСистема переходит к предусмотренной логике аварийного реагирования и не дДолжна ждать полного исчерпания ресурса.

ереход дДолжен происходить своевременно, исходя из прогнозируемой возможности безопасного завершения полёта.

## Mission Priority

Сохранение БВС и уже собранных данных имеет приоритет над продолжением миссии и получением дополнительных данных.
