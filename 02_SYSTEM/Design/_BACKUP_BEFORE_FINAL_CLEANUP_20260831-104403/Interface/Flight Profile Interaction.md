# Flight Profile Interaction

## Flight Profile Display

нтерфейс отображает рассчитанный профиль полёта дДля каждого БВС с учётом его персонального маршрута и назначенной задачи.

рофиль дДолжен быть связан с соответствующим С, его WP и временными параметрами.

## Route Profile

Для выбранного БВС отображаются основные параметры его маршрута:

- Departure;
- первая рабочая WP;
- рабочие WP;
- последняя WP задания;
- Destination;
- высота;
- скорость;
- курс;
- ETO;
- EET;
- ETA;
- Trip Time;
- Total Time.

## 2D / 3D Interaction

илот может просматривать профиль маршрута в 2D и 3D представлении.

2D представление используется дДля оценки маршрута на карте.

3D представление используется дДля оценки пространственного положения маршрута и высоты отдельных участков.

## Waypoint Interaction

WP могут редактироваться непосредственно на активной карте.

оложение WP изменяется захватом точки мышью и её перетаскиванием в требуемое положение.

После отпускания мыши новая позиция WP автоматически фиксируется.

ысота WP может изменяться отдельно от её горизонтального положения.

## Automatic Revalidation

После любого изменения исходных данных или WP сСистема автоматически выполняет повторную проверку маршрута.

При изменении положения или высоты WP сСистема автоматически выполняет повторную проверку и пПри необходимости перерасчёт маршрута.

После изменения маршрута повторно проверяются:

- ограничения;
- препятствия;
- требования задачи;
- ресурс С;
- временные параметры;
- конфликты с маршрутами других БВС.

## Table Synchronization

зменения маршрута, выполненные на карте, автоматически отражаются в таблице WP.

зменения разрешённых параметров маршрута в таблице автоматически отражаются на карте.

арта и таблица должны представлять одно и то же актуальное состояние рабочего маршрута.

## Profile and Mission State

рофиль полёта дДолжен отражать текущее состояние БВС и миссии.

зменение положения, телеметрии, ресурса или степени выполнения миссии автоматически обновляет соответствующие параметры интерфейса.

## Pilot Control

нтерфейс предоставляет пилоту возможность изменять предусмотренные параметры рабочего маршрута.

зменение параметров не должно приводить к непосредственному принятию сСистемой неподтверждённого маршрута.

аждое изменение проходит автоматическую проверку и, пПри необходимости, перерасчёт.

зменение рабочего профиДля полёта не изменяет ранее зафиксированные архивные записи миссии.

зменённое состояние пПосле фиксации может сохраняться как отдельная версия дДля последующего анализа и аудита.
