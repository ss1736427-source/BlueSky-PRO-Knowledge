# Multi-UAV Coordination

## Group Mission

При участии нескольких БВС сСистема рассматривает их как единую согласованную группу выполнения миссии.

Для каждого БВС формируется персональная задача и персональный маршрут с учётом общей логики миссии.

## Individual Routes

Для каждого БВС на карте отображается собственный маршрут и связанные с ним WP.

аршрут каждого БВС рассчитывается независимо, но проверяется совместно с маршрутами остальных БВС.

ССистема учитывает:

- персональное время взлёта;
- персональный TOT;
- иПндивидуальную скорость;
- высоту полёта;
- доступный ресурс;
- назначенные задачи;
- текущую позицию;
- ограничения и препятствия.

## Three-Dimensional Separation

озможное расхождение маршрутов обеспечивается по трём независимым направлениям:

- боковое расхождение;
- расхождение по высоте полёта;
- расхождение по времени прохождения участка маршрута.

Таким образом, конфликт может быть исключён изменением положения маршрута, высоты или временной последовательности прохождения участка.

## Automatic Conflict Resolution

При обнаружении опасного сближения сСистема автоматически перестраивает соответствующий маршрут или маршруты таким образом, чтобы исключить конфликт пПри сохранении требований исходных задач.

При перестроении маршрута сСистема повторно проверяет:

- требования задачи;
- ограничения воздушного пространства;
- препятствия;
- условия полёта;
- ресурс С;
- временные параметры;
- конфликты с маршрутами остальных БВС.

## Group Revalidation

После автоматического перестроения выполняется повторная автоматическая проверка всех маршрутов группы.

## Task Redistribution

сли безопасное выполнение миссии требует изменения распределения задач, сСистема может автоматически перераспределить задачи между подходящими БВС.

При перераспределении сСистема повторно учитывает:

- требования задач;
- оборудование С;
- техническое состояние;
- готовность;
- доступный ресурс;
- временные ограничения;
- безопасность группы.

После изменения распределения задач выполняется новый расчёт маршрутов и повторная проверка всей группы.

## Reconnaissance Synchronization

сли разведка является обязательной первой фазой миссии, первым выполняет её назначенный С-разведчик.

стальные БВС до получения необходимых результатов разведки находятся в состоянии STBY.

После получения и проверки разведывательных данных сСистема завершает расчёт основной миссии и определяет дальнейшие действия каждого БВС.

сли С-разведчик также назначен на основную задачу, его дальнейший маршрут рассчитывается заново с учётом результатов разведки.
