# Multi-UAV Coordination

## Group Mission

ри участии нескольких С система рассматривает их как единую согласованную группу выполнения миссии.

ля каждого С формируется персональная задача и персональный маршрут с учётом общей логики миссии.

## Individual Routes

ля каждого С на карте отображается собственный маршрут и связанные с ним WP.

аршрут каждого С рассчитывается независимо, но проверяется совместно с маршрутами остальных С.

Система учитывает:

- персональное время взлёта;
- персональный TOT;
- индивидуальную скорость;
- высоту полёта;
- доступный ресурс;
- назначенные задачи;
- текущую позицию;
- ограничения и препятствия.

## Route Conflict Detection

еред началом выполнения и после каждого изменения маршрута система автоматически проверяет маршруты всех С на возможность опасного сближения или конфликта.

роверка выполняется с учётом пространственного и временного положения С на маршруте.

Система должна учитывать возможность конфликта не только в одной точке, но и на пересекающихся или сближающихся участках маршрутов.

## Three-Dimensional Separation

озможное расхождение маршрутов обеспечивается по трём независимым направлениям:

- боковое расхождение;
- расхождение по высоте полёта;
- расхождение по времени прохождения участка маршрута.

Таким образом, конфликт может быть исключён изменением положения маршрута, высоты или временной последовательности прохождения участка.

## Automatic Conflict Resolution

ри обнаружении опасного сближения система автоматически перестраивает соответствующий маршрут или маршруты таким образом, чтобы исключить конфликт при сохранении требований исходных задач.

ри перестроении маршрута система повторно проверяет:

- требования задачи;
- ограничения воздушного пространства;
- препятствия;
- условия полёта;
- ресурс С;
- временные параметры;
- конфликты с маршрутами остальных С.

## Group Revalidation

осле автоматического перестроения выполняется повторная автоматическая проверка всех маршрутов группы.

зменение одного маршрута может повлиять на безопасность остальных маршрутов, поэтому проверка выполняется для всей группы.

аршрут считается подготовленным к выполнению только после успешного прохождения автоматической проверки на конфликты и ограничения.

## Task Redistribution

сли безопасное выполнение миссии требует изменения распределения задач, система может автоматически перераспределить задачи между подходящими С.

ри перераспределении система повторно учитывает:

- требования задач;
- оборудование С;
- техническое состояние;
- готовность;
- доступный ресурс;
- временные ограничения;
- безопасность группы.

осле изменения распределения задач выполняется новый расчёт маршрутов и повторная проверка всей группы.

## Reconnaissance Synchronization

сли разведка является обязательной первой фазой миссии, первым выполняет её назначенный С-разведчик.

стальные С до получения необходимых результатов разведки находятся в состоянии STBY.

осле получения и проверки разведывательных данных система завершает расчёт основной миссии и определяет дальнейшие действия каждого С.

сли С-разведчик также назначен на основную задачу, его дальнейший маршрут рассчитывается заново с учётом результатов разведки.

## Failure to Resolve Conflict

сли система не может построить безопасное взаимное расположение маршрутов при сохранении требований миссии, пилот должен быть уведомлён о невозможности безопасного планирования.

Система не должна считать миссию готовой к выполнению при наличии неразрешённого конфликта маршрутов.
