# UAV Availability and Readiness

## Administrative Data Source

 системе предусмотрен административный блок, содержащий сведения о техническом состоянии С и установленном на них оборудовании.

Система автоматически опрашивает административный блок для получения актуальных данных о:

- техническом состоянии каждого С;
- состоянии и готовности установленного оборудования;
- наличии оборудования, необходимого для выполнения конкретной задачи;
- технической готовности С к выполнению миссии;
- доступном ресурсе С.

## Mission-Specific Readiness

отовность С оценивается применительно к конкретной миссии, а не только как общее техническое состояние аппарата.

Технически исправный С может быть признан неподходящим для конкретной миссии, если его оборудование или возможности не соответствуют требованиям задачи.

Система сопоставляет возможности С с требованиями назначенных задач.

## Readiness Result

о результатам автоматического опроса система определяет готовность или неготовность каждого С к выполнению назначенной миссии.

езультат должен содержать:

- статус готовности;
- степень готовности;
- причину неготовности, если С не соответствует требованиям;
- сведения о недостающем оборудовании или ресурсе, если они являются причиной неготовности.

ля каждого С интерфейс отображает маркер степени готовности к выполнению данной миссии.

## Task Allocation Input

олученные сведения используются системой для определения состава участников миссии и распределения задач между С.

сли подходящих С несколько, система распределяет задачи между ними с учётом:

- оборудования;
- технического состояния;
- готовности;
- доступного ресурса;
- возможностей С;
- требований соответствующих задач.

сли подходящий С только один, система формирует миссию для него.

сли ни один доступный С не соответствует требованиям задачи, система не должна формировать ложную готовность миссии и должна сообщить пилоту, какого ресурса, оборудования или возможностей не хватает.

## Continuous Revalidation

анные о готовности С должны актуализироваться при изменении технического состояния, оборудования, ресурса или других параметров, влияющих на возможность выполнения миссии.

зменение таких данных должно автоматически инициировать повторную оценку готовности и при необходимости перерасчёт распределения задач и маршрутов.

## Reconnaissance Readiness

сли для получения недостающих данных требуется разведка, система выбирает С, соответствующий требованиям разведывательной задачи.

С-разведчик должен иметь необходимое оборудование и быть технически готовым к выполнению разведки.

стальные С, предназначенные для последующего выполнения основной миссии, до завершения обязательной разведки находятся в состоянии STBY.

## No False Readiness

Система не должна отображать С как готовый к конкретной задаче, если его оборудование, техническое состояние, ресурс или другие возможности не позволяют выполнить требования этой задачи.

ричина неготовности должна быть доступна пилоту для понимания результата автоматической оценки.
