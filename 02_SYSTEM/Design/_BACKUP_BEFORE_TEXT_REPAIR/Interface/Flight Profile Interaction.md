# Flight Profile Interaction

## Flight Profile Display

нтерфейс отображает рассчитанный профиль полёта для каждого С с учётом его персонального маршрута и назначенной задачи.

рофиль должен быть связан с соответствующим С, его WP и временными параметрами.

## Route Profile

ля выбранного С отображаются основные параметры его маршрута:

- Departure;
- первая рабочая WP;
- рабочие WP;
- последняя WP задания;
- Destination;
- высота;
- скорость;
- курс;
- ETO;
- EET;
- ETA;
- Trip Time;
- Total Time.

## 2D / 3D Interaction

илот может просматривать профиль маршрута в 2D и 3D представлении.

2D представление используется для оценки маршрута на карте.

3D представление используется для оценки пространственного положения маршрута и высоты отдельных участков.

## Waypoint Interaction

WP могут редактироваться непосредственно на активной карте.

оложение WP изменяется захватом точки мышью и её перетаскиванием в требуемое положение.

осле отпускания мыши новая позиция WP автоматически фиксируется.

ысота WP может изменяться отдельно от её горизонтального положения.

## Automatic Revalidation

осле любого изменения исходных данных или WP система автоматически выполняет повторную проверку маршрута.

ри изменении положения или высоты WP система автоматически выполняет повторную проверку и при необходимости перерасчёт маршрута.

осле изменения маршрута повторно проверяются:

- ограничения;
- препятствия;
- требования задачи;
- ресурс С;
- временные параметры;
- конфликты с маршрутами других С.

## Table Synchronization

зменения маршрута, выполненные на карте, автоматически отражаются в таблице WP.

зменения разрешённых параметров маршрута в таблице автоматически отражаются на карте.

арта и таблица должны представлять одно и то же актуальное состояние рабочего маршрута.

## Profile and Mission State

рофиль полёта должен отражать текущее состояние С и миссии.

зменение положения, телеметрии, ресурса или степени выполнения миссии автоматически обновляет соответствующие параметры интерфейса.

## Pilot Control

нтерфейс предоставляет пилоту возможность изменять предусмотренные параметры рабочего маршрута.

зменение параметров не должно приводить к непосредственному принятию системой неподтверждённого маршрута.

аждое изменение проходит автоматическую проверку и, при необходимости, перерасчёт.

## Archive Protection

зменение рабочего профиля полёта не изменяет ранее зафиксированные архивные записи миссии.

зменённое состояние после фиксации может сохраняться как отдельная версия для последующего анализа и аудита.
