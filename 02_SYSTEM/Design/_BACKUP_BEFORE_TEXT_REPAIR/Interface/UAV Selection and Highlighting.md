# UAV Selection and Highlighting

## UAV List

нтерфейс отображает список С, участвующих в миссии или доступных для её выполнения.

ля каждого С отображаются его актуальное состояние и степень готовности к назначенной задаче.

## UAV Selection

илот может выбрать конкретный С для детального просмотра его состояния, задачи и маршрута.

ыбор С не изменяет автоматически назначенную ему задачу или маршрут.

## Route Highlighting

ри выборе С его персональный маршрут должен быть явно выделен на карте.

Связанные с выбранным С WP также должны быть визуально связаны с ним.

аршруты остальных С остаются отображаемыми для понимания общей картины миссии.

## UAV Position

Текущее положение выбранного С отображается непосредственно на его маршруте и карте.

оложение С должно быть связано с его актуальным состоянием и телеметрией.

## Readiness Indicator

ля каждого С отображается маркер степени готовности к выполнению назначенной миссии.

сли С не готов, интерфейс должен предоставлять причину неготовности.

сли С находится в STBY, это состояние должно быть явно отображено.

## Mission Parameters

ри выборе С интерфейс предоставляет его персональные параметры, включая:

- назначенную задачу;
- персональный маршрут;
- WP;
- персональный TOT;
- ETO;
- EET;
- ETA;
- Trip Time;
- Total Time;
- состояние С;
- состояние батареи или другого источника энергии;
- уровень телеметрии.

## Multi-UAV Context

ри участии нескольких С выбор одного С не должен скрывать информацию, необходимую для понимания взаимодействия всей группы.

илот должен иметь возможность одновременно оценивать персональное состояние выбранного С и общую ситуацию миссии.

## State Synchronization

зменение состояния, положения, телеметрии, ресурса или степени выполнения выбранного С автоматически отражается в интерфейсе.

зменения маршрута выбранного С должны автоматически отражаться на карте и в соответствующей таблице маршрута.

## Pilot Interaction

нтерфейс должен обеспечивать быстрое переключение между С без необходимости перехода в отдельный режим управления каждым аппаратом.

ыбор С является операцией просмотра и анализа, если иное действие явно не выбрано пилотом.
