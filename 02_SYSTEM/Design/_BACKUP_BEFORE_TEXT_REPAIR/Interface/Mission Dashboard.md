## UAV Panel Display Configuration

анель каждого С должна иметь индивидуальную настройку отображаемых параметров.

астройка используется как фильтр отображаемой информации и предназначена для предотвращения перегрузки интерфейса избыточными данными.

илот должен иметь возможность выбрать, какие параметры отображаются на панели конкретного С.

## Display Parameter Selection

астройке подлежат отображаемые параметры панели С, включая доступные системе:

- состояние С;
- готовность;
- положение;
- степень выполнения миссии;
- батарея или другой источник энергии;
- телеметрия;
- ETD;
- TOT;
- ETO;
- EET;
- ETA;
- Trip Time;
- Total Time;
- состояние маршрута;
- статус взаимодействия с С р;
- другие предусмотренные параметры.

еречень отображаемых параметров должен быть настраиваемым и не должен ограничиваться обязательным отображением всех доступных данных одновременно.

## Ergonomic Layout

При выборе параметров система автоматически размещает отображаемую информацию на панели С эргономично.

азмещение должно обеспечивать читаемость выбранных параметров и не допускать неоправданного наложения или визуальной перегрузки элементов.

ри изменении набора отображаемых параметров компоновка панели автоматически адаптируется.

## Apply to All — UAV Panels Only

Функция «Применить для всех» предусмотрена только для панелей БВС.

При выборе этой функции текущая настройка отображаемых параметров применяется ко всем панелям БВС миссии.

После применения общей настройки пилот может изменить конфигурацию отдельной панели БВС индивидуально.

Для верхней, нижней, левой и правой панелей, а также для карты функция «Применить для всех» не применяется.
## Display Configuration Persistence

ыбранная настройка отображаемых параметров должна сохраняться в рамках текущей конфигурации интерфейса.

зменение отображения параметров не изменяет исходные данные миссии, маршрут или состояние С.

астройка влияет только на представление информации в интерфейсе.

## Information Availability

Скрытие параметра на панели не означает прекращение его получения, расчёта или контроля системой.

анные продолжают обрабатываться системой независимо от того, отображаются они на панели С или нет.

ритические состояния и предупреждения не должны становиться недоступными вследствие фильтра отображаемых параметров.

## Interface Panel Display Configuration

аждая отдельная область интерфейса должна иметь собственную настройку отображаемой информации.

астройка применяется отдельно к:

- верхней панели;
- нижней панели;
- левой панели;
- правой панели;
- карте.

аждая область интерфейса рассматривается как самостоятельная информационная панель со своим набором отображаемых параметров.

## Display Filter

ля каждой панели должна быть предусмотрена настройка отображаемых параметров в виде фильтра.

илот может выбрать, какие доступные параметры отображаются в конкретной панели.

Фильтр изменяет только представление информации и не отключает получение, расчёт, контроль или обработку соответствующих данных системой.

## Panel-Specific Configuration

астройка одной панели не должна автоматически изменять настройки других панелей.

илот может независимо настроить:

- верхнюю панель;
- нижнюю панель;
- левую панель;
- правую панель;
- карту.

то позволяет формировать индивидуальную эргономичную конфигурацию рабочего пространства.

## Ergonomic Layout

осле выбора отображаемых параметров система автоматически размещает их в соответствующей панели эргономично.

омпоновка должна адаптироваться к количеству и составу выбранных параметров.

нформация должна оставаться читаемой и не создавать неоправданной визуальной перегрузки.

## Map Configuration

арта также должна иметь собственную настройку отображаемой информации.

илот может выбирать отображение предусмотренных элементов карты, включая:

- маршруты С;
- WP;
- Departure;
- Destination;
- рабочую область;
- ограничения;
- препятствия;
- текущие положения С;
- другие доступные пространственные данные.

Скрытие элемента карты влияет только на его визуальное отображение и не отключает его участие в расчётах и проверках системы.

## Configuration Persistence

астройки отображения должны сохраняться как конфигурация интерфейса.

зменение настроек отображения не изменяет исходные данные миссии, рассчитанные маршруты, состояние С или результаты расчётов.

## Critical Information

ритические состояния, аварийные предупреждения и информация, требующая обязательного внимания пилота, не должны становиться недоступными вследствие настройки фильтра отображения.

Система должна обеспечить их обязательное визуальное представление независимо от пользовательской конфигурации панели.
