# Dynamic Return Calculation

## Purpose

аршрут возврата С рассчитывается динамически на протяжении выполнения миссии.

Система постоянно определяет дистанцию от текущего положения С до Destination с учётом реально выполнимой траектории возврата.

## Real Return Distance

езопасность возврата оценивается не по прямому расстоянию до Destination, а по реально выполнимой траектории.

ри определении возможности возврата система учитывает:

- окружающую обстановку;
- условия полёта;
- ограничения воздушного пространства;
- препятствия;
- необходимость обхода ограничений и препятствий;
- силу и направление ветра;
- текущее положение С.

## UAV Resource

ри расчёте возврата система учитывает текущее состояние и доступный ресурс конкретного С.

Учитываются, в зависимости от типа аппарата и доступных данных:

- состояние батареи;
- запас другого источника энергии;
- техническое состояние;
- количество исправных двигателей;
- другие параметры, влияющие на возможность безопасного полёта.

## Continuous Recalculation

Система использует постоянно обновляемые данные для расчёта и корректировки траектории возврата.

ри изменении:

- положения С;
- условий среды;
- ограничений;
- препятствий;
- ветра;
- состояния аппарата;
- доступного ресурса;

расчёт возврата должен актуализироваться.

## Return Feasibility

Система должна своевременно определить, сохраняется ли возможность безопасного возврата с учётом имеющегося ресурса С.

ценка выполняется для реально выполнимой траектории, а не только по геометрической дистанции.

## Automatic Return Route Update

сли текущая траектория возврата перестаёт соответствовать требованиям безопасности, система должна рассчитать актуальную безопасную траекторию с учётом новых условий.

зменение маршрута возврата должно проходить автоматическую проверку ограничений, препятствий, ресурса и других параметров безопасности.

## Emergency Transition

сли безопасный возврат становится невозможным, система переходит к предусмотренной логике аварийного реагирования и не должна ждать полного исчерпания ресурса.

ереход должен происходить своевременно, исходя из прогнозируемой возможности безопасного завершения полёта.

## Mission Priority

Сохранение С и уже собранных данных имеет приоритет над продолжением миссии и получением дополнительных данных.

родолжение выполнения основной задачи не должно происходить ценой потери возможности безопасного возврата С.
