# ATC / ES ORVD Response and Error Learning

## Learning Loop

Система использует фактические ответы ЕС ОрВД как обратную связь для повышения качества формирования планов полёта.

Цикл обучения:

ФОРМИРОВАНИЕ ПЛАНА → ПОДАЧА → ОТВЕТ ЕС ОРВД → АНАЛИЗ → ВЫЯВЛЕНИЕ ОШИБКИ → ИСПРАВЛЕНИЕ → ПОВТОРНАЯ ПОДАЧА → СОХРАНЕНИЕ РЕЗУЛЬТАТА.

## Error Handling

При обнаружении ошибки система должна сохранить связь между исходной версией плана, полученным ответом, ошибочным элементом и исправленной версией.

Исправление должно быть явно представлено пилоту на этапе Human-in-the-Loop.

Система должна запоминать подтверждённые способы исправления для последующего формирования аналогичных планов.

## Learning Safety

Обучение системы не должно изменять архивную первичную запись отправленного плана или полученного ответа.

Обучающие данные являются производными данными и должны сохранять ссылку на исходную архивную запись.

## Autonomy Gate

Переход к самостоятельной подаче допускается только после накопления достаточной статистики успешной работы и при наличии явного подтверждения оператора.

После перехода в автоматический режим система продолжает контролировать ответы ЕС ОрВД и фиксировать ошибки и результаты их обработки.

## Key Innovation

Ключевая особенность системы - замкнутый контур обучения на фактической обратной связи ЕС ОрВД: система не только формирует план, но и учится на результатах его фактической подачи, постепенно повышая степень автономности при сохранении контроля оператора.
