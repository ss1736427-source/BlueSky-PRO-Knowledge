# Mission Formation

## Departure

При переходе в кабину система автоматически определяет исходное место старта миссии (Departure) по фактическому GPS-положению оператора.

Определённая по GPS точка Departure отображается на карте и используется как исходная точка расчёта.

Пилот может назначить другое место Departure любым предусмотренным удобным способом, включая перетаскивание точки на карте или ввод известных координат.

## Working Area

Система формирует рабочую область в соответствии с определённой задачей и предлагает её пилоту для уточнения.

Пилот может скорректировать предлагаемую область непосредственно на карте.

## Destination

После определения рабочей области система предлагает Destination.

По умолчанию Destination определяется как место оператора с передатчиком.

Для аварийного режима Destination определяется заранее установленным фиксированным местом.

## Data Acquisition

После определения Departure, рабочей области и Destination система автоматически запускает сбор и проверку исходных данных.

Система опрашивает административный блок для получения данных о БВС, их оборудовании, техническом состоянии и готовности.

Система опрашивает ХАБ для получения внешних данных, необходимых для планирования и расчёта, включая данные о районе полётов и доступные внешние данные по интеграционным каналам.

После получения данных система автоматически определяет, достаточно ли их для расчёта основной миссии.

## Reconnaissance Decision

Если данных достаточно, система выполняет распределение задач и расчёт маршрутов готовых БВС.

Если для безопасного и корректного расчёта недостаточно данных и требуется разведка, система выделяет разведывательный этап отдельно и первым запускает БВС-разведчик.

Остальные БВС до получения необходимых результатов разведки находятся в состоянии STBY.

После получения и проверки результатов разведки система автоматически завершает необходимые расчёты, при необходимости перераспределяет задачи и рассчитывает основные маршруты.

## Mission Ready State

После расчёта система отображает маршруты всех БВС на карте в 2D и 3D, заполняет индикаторы интерфейса и предоставляет таблицы маршрутов.

Перед выполнением система автоматически проверяет маршруты на ограничения, препятствия и конфликты между БВС.

При необходимости маршруты автоматически перестраиваются с повторной проверкой.

После успешного завершения расчёта и проверки система формирует согласованный набор маршрутов и задач, готовый к выполнению миссии.
